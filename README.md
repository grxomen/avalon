# Avalon Bot 🎭

**Avalon Bot** is a fully automated Discord bot for playing *The Resistance: Avalon* — the classic social deduction game of hidden roles, secret voting, and strategic deception. No manual setup, no spreadsheets, just immersive, streamlined gameplay directly in your server.

---

## 🎮 What It Does

- Handles full Avalon game flow automatically
- Assigns roles and sends private messages
- Manages team selection, voting, and quest outcomes
- Tracks rounds, win conditions, and endgame events
- Offers clean, clear interaction through Discord messages

---

## 🧙‍♂️ Supported Roles

Customize each game with standard or optional roles:

**Good:**
- Merlin
- Percival
- Loyal Servants of Arthur

**Evil:**
- Assassin
- Morgana
- Mordred
- Oberon
- Minions of Mordred

Role selection can be configured per game or preset in settings.
